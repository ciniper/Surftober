Surftober 2026 trophy — the spinner

A fully printed fidget-spinner fridge magnet: a 608 bearing, a wave ring on arms that animates on a phone video, a still hub with the name. Everything below reads one config file, spinner-config.js, so the previews and the printed parts always agree.

Running it

The configurator's Generate button needs the little local server (it runs the CadQuery generator for you and serves the output back):

cd design/trophy/cad && ./setup.sh        # once: venv + CadQuery (Homebrew python3.12, node)
.venv/bin/python serve.py 8930           # then open http://localhost:8930/

Any static server works for the previews alone (python3 -m http.server --directory design/trophy); the viewer then shows the generator command instead of running it. Both pages load three.js from unpkg, so stay online. Not file:// — ES modules.

URL options

Both pages share them, so a configured link can be passed around: name=KAI · tier=gold|silver|bronze|participant · arms=3|4 · wave=classic|rolling|return|barrel|returntip|classictip|plover · version=v3 (output file prefix) · frames=6…16 · art=inlay|raised|none · text=recessed|inlay|raised · weight=none|bezel|cog · bezel=flat|round · cap=orange|navy|teal · parts=body,wave-water,… · preset=testring. The viewer's Copy link button writes the current state.

Generated files land in design/trophy/cad/out/ (gitignored). Build notes, sourcing and the decision log: README.md.
